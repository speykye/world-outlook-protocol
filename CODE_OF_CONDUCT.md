# Code of Conduct

This project follows a simple contribution standard: be respectful, stay on scope, and avoid exposing private creative work.

## Expected behavior

- Discuss ideas professionally.
- Keep feedback specific and actionable.
- Respect creators' unpublished settings, drafts, and worldbuilding materials.
- Use synthetic examples instead of private projects when reporting bugs.
- Accept that not every workflow request belongs in the public protocol.

## Unacceptable behavior

- Harassment, insults, threats, or personal attacks
- Publishing another person's private creative materials
- Pressuring maintainers to implement personal workflow customizations
- Using issues to promote unrelated tools or services
- Repeatedly reopening closed scope decisions without new technical evidence

## Enforcement

Maintainers may edit, hide, lock, or delete comments and issues that violate this code of conduct or expose private data. Maintainers may also block users who repeatedly disregard project boundaries.

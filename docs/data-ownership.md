# Data Ownership / 数据所有权说明

梦划奇点的协议层应坚持以下原则：

1. 用户创作资料属于用户。
2. 导出包应尽量可读、可备份、可迁移。
3. 工具可以提供结构化能力，但不应把用户资料锁死在私有格式里。
4. 本地优先数据不等于不可迁移；本协议的存在就是为了降低迁移成本。
5. 公开分享、共创包、云同步等能力必须与完整私有备份区分开。

## Recommended UI wording

面向普通用户时，优先使用：

- “备份文件”而不是“JSON”；
- “可迁移资料包”而不是“协议数据”；
- “检查资料包是否完整”而不是“validate schema”。

面向开发者和工具作者时，可以使用：

- protocol；
- schema；
- validator；
- migration；
- interoperability。

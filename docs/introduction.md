# Introduction / 简介

World Outlook Protocol（梦划奇点资料协议）是一套面向世界观创作者的资料交换格式草案。

它的目标不是把创作资料锁进某一个工具，而是让用户的世界观资料可以：

- 被完整导出；
- 被普通文本工具检查；
- 被第三方工具读取；
- 在未来版本之间迁移；
- 在协作、共创、备份和长期保存中保持结构清晰。

## 当前边界

本协议只定义公开交换层：世界、模块、条目、关系、历法、时间线、地图索引、资料片段、写作上下文包等数据形状。

它不定义完整产品 UI，不定义商业 Skill Prompt，不定义私有数据库实现，也不定义平台级协作、支付、争议处理或证据链能力。

## Versioning

当前协议 ID：`world-outlook-v0.1`。

当前应用导出包版本仍沿用产品内部导出版本，例如 `1.9.0`。后续建议逐步过渡到：

```json
{
  "meta": {
    "protocol": "world-outlook-v0.1",
    "appName": "梦划奇点",
    "appVersion": "0.x"
  },
  "version": "1.9.0"
}
```

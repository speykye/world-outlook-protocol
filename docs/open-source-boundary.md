# Open Source Boundary / 开放边界

This package represents the open protocol layer, not the full product.

## Open now

- protocol documents
- export bundle shape
- TypeScript public data model
- JSON Schema draft
- lightweight validator
- example bundles and templates

## Not included

- complete Angular application source
- production UI implementation
- internal local database repositories
- commercial writing Skill prompts
- full browser LLM workflow implementation
- time-shards / skreeb-new integration details
- high-resolution logo, brand assets and marketing source files

## Rationale

The protocol should be open early because it builds trust: users can inspect, preserve and migrate their data.

The full application should not be opened before the product direction, UX language, data model and commercial boundary are stable enough to avoid fragmented forks and premature maintenance pressure.

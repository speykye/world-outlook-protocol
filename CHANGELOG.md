# Changelog

All notable changes to World Outlook Protocol will be documented in this file.

This project follows semantic versioning once the protocol reaches `v1.0`. Before `v1.0`, breaking changes may happen, but they should be documented.

## [0.1.0-alpha.1] - 2026-05-28

### Added

- Initial public draft of World Outlook Protocol.
- Added TypeScript protocol types for worlds, modules, entries, relations, timelines, calendars, map indexes, wiki items, inspiration items, and writing context packages.
- Added JSON Schema draft for `WorldExportBundle`.
- Added lightweight validator and CLI entry.
- Added minimal example bundle.
- Added fantasy template example bundle.
- Added documentation for bundle format, migration policy, data ownership, and open-source boundary.

### Notes

- This is an alpha protocol draft.
- Compatibility is not guaranteed before `v1.0`.
- This repository does not include the full World Outlook / 梦划奇点 application source code.

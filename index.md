# World Outlook Protocol / 梦划奇点世界观资料协议

Open data protocol, TypeScript types, JSON Schema, validator, and examples for structured worldbuilding exports.

梦划奇点世界观资料协议，用于描述世界观资料的导出、迁移、校验和长期保存格式。

> This repository contains only the open protocol layer.  
> 本仓库只开放协议层，不包含完整应用源码、界面实现、写作助手 Prompt 或商业模板。
